## Changes

1. **Cut-off heads (storage only).** `faceCutByFrameEdge` (`src/server/faceFrameEdge.ts`): a stranger face is stored only when its box stays `FACE_STRANGER_MIN_EDGE_MARGIN` (0.10) of its own size inside every frame edge. Observations carry `frameSize`. Calibrated on the 15 live stranger faces: catches the 3 cut heads (0/9/27 px from the bottom edge), keeps the nearest complete face (50 px, limit 46). New suppression reason `stranger-cut-off`.
2. **Shared-stream door scans.** The pipeline stream reader can split its one decode into a second output of whole-picture JPEGs (`DOOR_SCAN_SNAPSHOT_FPS` 4/s, newest 8 in memory, `pipe:3`). `performGateScan` uses them when the gate's pipeline stream for that camera is live; otherwise (pipeline `legacy`, stream down, other camera, body `url`) it dials as before. `DOOR_SCAN_SHARED_STREAM=false` = old behaviour. Scan results carry `streams[].captureSource`; the watcher runtime `lastCaptureSource` / `lastCaptureMs`. Door decisions, thresholds and fusion unchanged.
3. **Gate UI** (frontend agent handoff `2026-10-01-gate-ui.md`).
4. **Gate on/off admin-only** in `applyGateConfigPatch` (found by the frontend agent).

Env: new optional `FACE_STRANGER_MIN_EDGE_MARGIN`, `DOOR_SCAN_SHARED_STREAM`, `DOOR_SCAN_SNAPSHOT_FPS` (.env.example, docker-compose.yml). No schema change.
